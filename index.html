Session summary

Using an AI agent to manage Canvas courses

The Canvas Command Center approach shows how an instructor can pair Hermes Agent (an open-source AI agent that runs on your own computer) with the Canvas REST API and Google Docs to review, analyze, and update course content, taking the repetitive clicking out of course management.

What it is

A local AI agent (Hermes) that can read Canvas course data through the API and propose changes, plus a dashboard to browse courses, modules, pages, assignments, discussions, quizzes, and files.

What you need

  • PowerShell 7
  • Hermes Agent
  • A Canvas Access Token
  • An AI model key (e.g., Google AI Studio)
  • Node.js LTS (for this dashboard's local proxy)

Key cautions

  • Penn State now issues Canvas tokens only through a Help Desk ticket (since May 20, 2026).
  • Check approval for installing software and for sending course data to an AI model.
  • Keep student records out of AI prompts and reports.
